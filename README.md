# 归墟录

> 中式心理恐怖 · Windows XP 风格 · 网页 ARG 游戏

一个伪装成 2001 年个人网站的交互式恐怖叙事游戏。在 Windows XP 的复古界面下，玩家通过浏览一个名为"归墟小筑"的神秘网站，逐步揭开鹤城归墟村消失的真相。

## 游戏特色

- **复古 XP 系统**：完整的 Windows XP 桌面模拟，含开机动画、IE 浏览器、记事本、我的电脑、回收站
- **多分支叙事**：3 条主线 × 3 条支线，共 6 个不同结局
- **关键词日记解锁**：14 篇加密日记需要发现隐藏关键词才能解锁
- **渐进式恐怖**：从微妙违和感到心理压迫，恐怖随探索深度递增
- **线索高亮系统**：15 个关键线索在文本中高亮显示，区分已/未发现状态
- **心理恐怖效果**：低语、暗影、屏幕故障、文字腐败、第四面墙打破等 12 种效果

## 如何游玩

直接在浏览器中打开 `index.html` 即可开始游戏。

```bash
# 或者用本地服务器
python3 -m http.server 8080
# 访问 http://localhost:8080
```

## 文件说明

| 文件 | 说明 |
|------|------|
| `index.html` | 游戏本体（单文件，~240KB，内嵌全部资源） |
| `攻略.md` | 完整通关攻略（6 结局 + 14 关键词 + 全部选择点） |
| `设计方案.md` | 游戏世界观、剧情、网站结构、谜题系统设计 |
| `分支叙事系统.md` | 数值系统、选择点、结局条件、影响矩阵设计 |

## 结局一览

| 结局 | 名称 | 触发条件 |
|------|------|----------|
| 好结局 | 归乡者 | 信任 ≥ 8 + 留下 |
| 坏结局 | 遗忘者 | 信任 < 8 + 离开 |
| 真结局 | 循环 | 好结局后触发 |
| 隐藏 A | 守护者 | 信任路线深层 |
| 隐藏 B | 毁灭者 | 知识 ≥ 6 + 恐惧 ≤ 6 + 离开 |
| 隐藏 C | 门 | 特殊日记触发 |

> 不剧透更多了。自己探索吧。

## 技术实现

- 纯 HTML + CSS + JavaScript，无外部依赖
- 单文件架构，约 1400 行代码
- 使用 localStorage 存档
- CSS 动画实现恐怖效果
- 正则表达式实现线索文本匹配

## 推荐环境

- 现代浏览器（Chrome / Firefox / Edge / Safari）
- 建议全屏游玩以获得最佳沉浸感
- 建议佩戴耳机
